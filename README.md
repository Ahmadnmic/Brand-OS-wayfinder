# Brand OS wayfinder

The planning map for Brand OS, kept as GitHub Issues:

- The issue labelled `wayfinder:map` is the map: destination, decisions so far,
  and the fog of war still to clear.
- Its sub-issues are decision tickets (`wayfinder:grilling`, `wayfinder:prototype`,
  `wayfinder:research`, `wayfinder:task`). Open, unblocked, unassigned tickets are
  the frontier.

Product code does not live here. Companion documents do: `GLOSSARY.md`,
`docs/adr/`, `docs/research/`.
