# Brand OS: wayfinder map

This repository is the planning home for **Brand OS**. Its GitHub Issues hold the
wayfinder map (label `wayfinder:map`) and the decision tickets under it. Product
code lives elsewhere; this repo keeps the map's companion documents only:
`GLOSSARY.md`, `docs/adr/` and `docs/research/`.

Start every session by loading the map issue, not the whole ticket history.

## Agent skills

### Issue tracker

Issues live in this repo's GitHub Issues (`Ahmadnmic/Brand-OS-wayfinder`), driven
with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and one `docs/adr/` at the repo root.
See `docs/agents/domain.md`.

### Research notes

Findings from `research` tickets go in `docs/research/<ticket-slug>.md`, one
file per ticket, each claim cited to its primary source.
